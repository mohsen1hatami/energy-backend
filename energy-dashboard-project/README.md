# داشبورد پایش انرژی

## اجرای محلی
```bash
npm install
npm run dev
```
آدرس چاپ‌شده در ترمینال (معمولاً http://localhost:5173) را باز کنید.

## داده
داده فعلی عکس‌فوری واقعی خروجی `build_dashboard_data.py` است که در `src/App.jsx`
به‌صورت ثابت `DASHBOARD_DATA` جاسازی شده. برای به‌روزرسانی، پایپ‌لاین پایتون را
دوباره اجرا کنید و محتوای `dashboard_data.json` جدید را جایگزین همان ثابت کنید.

## بالا آوردن روی اینترنت

### گزینه ۱ — گیت‌هاب + Vercel (پیشنهادی، ساده‌ترین راه)
1. کد را در یک مخزن گیت‌هاب پوش کنید (به گام‌های چت مراجعه کنید).
2. وارد vercel.com شوید و با اکانت گیت‌هاب خود وارد شوید.
3. "New Project" → مخزن را انتخاب کنید → Vercel به‌طور خودکار Vite را تشخیص می‌دهد → Deploy.
4. یک آدرس زنده مثل `your-project.vercel.app` می‌گیرید؛ با هر push به شاخه اصلی، دوباره خودکار دیپلوی می‌شود.

نیازی به تغییر هیچ فایلی (از جمله `vite.config.js`) برای این روش نیست.

### گزینه ۲ — گیت‌هاب Pages
یک فایل GitHub Actions (`.github/workflows/deploy-pages.yml`) از قبل در این پروژه
آماده شده. مراحل:
1. کد را پوش کنید.
2. در repo روی گیت‌هاب: Settings → Pages → بخش Source را روی "GitHub Actions" بگذارید.
3. **مهم:** پیش از پوش، در `vite.config.js` مقدار `base` را برابر نام مخزن‌تان بگذارید،
   مثلاً اگر اسم مخزن `energy-dashboard` است:
   ```js
   export default defineConfig({
     plugins: [react()],
     base: "/energy-dashboard/",
   });
   ```
   بدون این تنظیم، فایل‌های CSS/JS روی گیت‌هاب Pages درست بارگذاری نمی‌شوند.
4. بعد از اولین push به شاخه main، در تب Actions می‌توانید پیشرفت دیپلوی را ببینید؛
   آدرس نهایی چیزی مثل `https://USERNAME.github.io/energy-dashboard/` خواهد بود.

## ساخت نسخه نهایی دستی
```bash
npm run build
```
خروجی در پوشه `dist/` است و روی هر هاست استاتیک دیگری هم قابل آپلود است.
