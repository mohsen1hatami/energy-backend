# Energy Platform API

سرویس FastAPI برای تحلیل قبض برق (PDF) و پیش‌نمایش داده کیفیت توان (CSV).

## اجرای محلی
```bash
pip install -r requirements.txt
uvicorn main:app --reload
```
سپس مرورگر را روی http://127.0.0.1:8000/docs باز کنید — مستندات تعاملی Swagger
خودکار ساخته می‌شود و می‌توانید مستقیماً از همان صفحه فایل آپلود کنید.

## اندپوینت‌ها
- `GET /health` — بررسی سلامت سرویس
- `POST /api/bill/parse` — آپلود PDF قبض؛ خروجی: تمام اقلام استخراج‌شده و صحت‌سنجی‌شده
- `POST /api/tariff/estimate` — آپلود PDF قبض + دو پارامتر فرم (`peak_reduction_percent`,
  `shift_to_offpeak_percent`) — مقایسه هزینه فعلی با سناریوی فرضی
- `POST /api/pq/preview` — آپلود CSV کیفیت توان؛ خروجی: تعداد ردیف، ستون‌های نرمال‌شده، نمونه داده

## دیپلوی روی Render
این پروژه یک `Dockerfile` آماده دارد (چون برای پردازش PDF به ابزار سیستمی
`poppler-utils` نیاز است که فقط با نصب سراسری/Docker در دسترس می‌شود، نه با
pip). مراحل دقیق در چت توضیح داده شده.

## محدودیت فعلی
- حداکثر حجم فایل: ۱۰ مگابایت
- بدون احراز هویت — قبل از استفاده عمومی گسترده، لایه امنیتی اضافه شود
- `pdf_parser` روی قالب PDF شرکت توزیع نیروی برق خراسان شمالی (Crystal Reports)
  کالیبره شده؛ شرکت‌های توزیع دیگر ممکن است قالب متفاوتی داشته باشند
